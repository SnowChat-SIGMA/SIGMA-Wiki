# SIGMA-Wiki

snowtice(시그마) SNOWCHAT 챗봇이 읽는 공지 위키입니다.

- 숙명여대 **공개 게시판**의 공지를 정리한 참고 자료만 담습니다. 개인정보와 내부 자료는 넣지 않습니다.
- 원래는 `sigma-pipeline`이 매일 자동으로 생성해 push합니다. **페이지를 손으로 고치지 마세요.** 다음 날 덮어써집니다. 고칠 내용은 pipeline 템플릿이나 추출 결과에서 고칩니다.
- 지금은 SNOWCHAT 연동 테스트용으로 페이지 몇 개를 수동으로 올려 둔 상태입니다.

## 구조

| 파일 | 역할 |
|---|---|
| `index.md` | 유효한 페이지 목록. 챗봇이 **가장 먼저** 읽고 어떤 페이지를 열지 고릅니다 |
| `pages/*.md` | 실제 내용. 절차·행사·규정 단위로 한 파일씩 |
| `tools/build_index.py` | `pages/`의 머리 4줄을 읽어 `index.md`를 다시 만듭니다 |

## 페이지 규칙

모든 페이지의 첫 4줄은 아래 형식을 지킵니다. `build_index.py`가 이 4줄로 목록을 만듭니다.

```
# [절차|행사|규정|안내] 제목
분야: ... | 대상: ... | 상태: ... | 유효기간: YYYY-MM-DD ~ YYYY-MM-DD | 갱신: YYYY-MM-DD
키워드: 학생이 물어볼 법한 단어, 쉼표로 구분
요약: 한 문장
```

본문 규칙은 아래와 같습니다.
- 섹션 제목마다 맥락을 반복합니다. 예: `## 단계별 일정 (2027년 2월 졸업 · 수학과)`
- 일정은 표 대신 목록으로 씁니다.
- 원문에 없는 값은 `원문에 없음 [확인 필요]`로 씁니다. 추측하지 않습니다.
- 끝에 근거 공지 링크와 문의처, 안내 문구를 둡니다.
- 유효기간이 지난 페이지는 `pages/`에서 **삭제**합니다. 기록은 커밋 이력에 남습니다.

## index.md 다시 만들기

```bash
python tools/build_index.py           # index.md 생성
python tools/build_index.py --check   # 형식 검사만
```
